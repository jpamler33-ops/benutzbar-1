# Sample library attribution

All shipped **WAV audio one-shots** under `samples/` are redistributed from [Boochi44/free-drum-samples](https://github.com/Boochi44/free-drum-samples), which marks its pack **Creative Commons Zero 1.0 (CC0-1.0)**. Its own README says some sounds derive from a documented TR-808 recording project (Michael Fischer / TidalCycles, CC0) and some 808s were rendered with DSP by the pack author. The app does **not synthesize** drum/bass events during playback: it triggers these prerecorded files.

Upstream sample manifest: https://github.com/Boochi44/free-drum-samples/blob/main/beatpacks-config.ts
Source repo: https://github.com/Boochi44/free-drum-samples
License: https://creativecommons.org/publicdomain/zero/1.0/

**Scope:** This permission covers the WAV samples. It does not imply that all imported music references are copyright-free. Melodies and chords in BeatForge continue to use its built-in synthesizer.

**Tuning:** Some 808 one-shots do not publish an exact musical root key. The sampler defaults to C2 (MIDI 36) and exposes an editable root-note selector. This is a starting assumption, not a measured calibration.
